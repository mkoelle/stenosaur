# pkg/controller/ui — Agent Instructions

@../../../AGENTS.md

## Layer Role

This directory contains all HTML, templates, and static assets for the web admin UI. It is rendered server-side via **Templ** and made interactive via **HTMX** and **Alpine.js**. (ADR-007)

## Tooling Rules (ADR-007)

| Rule | Detail |
|---|---|
| **Templ only** | All HTML is in `.templ` files. Never use `html/template` or write raw HTML strings in Go code. |
| **HTMX for server interactions** | HTTP calls, partial DOM replacement, WebSocket/SSE — use HTMX attributes. No custom `fetch()`. |
| **Alpine.js for local state** | Toggling panels, confirmation dialogs, ephemeral UI state only. No Alpine for server calls. |
| **Tailwind CSS only** | Use utility classes only. No custom CSS files other than `tw.css` (generated). |
| **Vendored assets** | HTMX and Alpine.js are in `static/`. Never load from a CDN at runtime. |
| **Run `task generate` after edits** | `.templ` → `*_templ.go` generation is required before `go build`. |

## File Layout

```
ui/
  layout.templ        # base HTML shell; imports HTMX, Alpine.js, Tailwind
  dashboard.templ     # status panel, start/stop controls, source config form
  logs.templ          # live WebSocket log tail
  static/
    htmx.min.js       # vendored — do not replace with CDN link
    alpine.min.js     # vendored — do not replace with CDN link
    tw.css            # generated by Tailwind CLI — do not hand-edit
    tw.src.css        # Tailwind source (directives only); hand-edit this
```

## HTMX Patterns for This UI

```html
<!-- Poll /status every 2s and swap the #pipeline-metrics div -->
<div id="pipeline-metrics"
     hx-get="/status"
     hx-trigger="every 2s"
     hx-target="#pipeline-metrics"
     hx-swap="innerHTML">
</div>

<!-- POST /start with auth header on button click -->
<button hx-post="/start"
        hx-headers='{"Authorization": "Bearer {{.Token}}"}'
        hx-confirm="Start streaming?">
  Start
</button>

<!-- WebSocket log tail via HTMX WebSocket extension -->
<div hx-ext="ws" ws-connect="/logs">
  <div id="log-output"></div>
</div>
```

## Alpine.js Patterns for This UI

```html
<!-- Confirmation dialog before Stop -->
<div x-data="{ confirm: false }">
  <button @click="confirm = true">Stop</button>
  <div x-show="confirm">
    <p>Leave the meeting?</p>
    <button hx-post="/stop" @click="confirm = false">Yes</button>
    <button @click="confirm = false">Cancel</button>
  </div>
</div>
```

## Do Not

- Fetch from a CDN at runtime (HTMX, Alpine, Tailwind must all be vendored)
- Write JavaScript outside of `x-` Alpine attributes or HTMX config
- Use `html/template` anywhere in this directory
- Hand-edit `tw.css` — edit `tw.src.css` and run `task generate`
- Add a JS framework (React, Vue, Svelte) without an ADR-007b update
