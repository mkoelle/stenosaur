# Stenosaur Project Plan

## Objectives
The stenosaur project aims to be a containerized zoom agent with a web front end encompassing multiple features, the ability to play selected audio, music, and streaming media as the mic in and webcam video instead of as a shared screen.

## Scope
- Ability to display a web page as the webcam video feed
- Ability to play audio from a web page as the mic in
- Web app to manage the instance and submit URLs for display or play
- Ability to transcribe meeting
- Ability to duck audio when people are speaking
- Playlist creation and management

## Timeline
Timeline is as inspiration allows. First milestone: when it can connect to a zoom session, play triggered audio through the mic and display a webpage as a webcam image.
